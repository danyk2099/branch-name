Branch name settings

Issue type prefixes

Type names are matched ignoring case, spaces and dashes, so Sub-task also matches Subtask. If your Jira uses other names (for example Hebrew ones such as באג), add them here too.

Jira issue typePrefixRemove

Translation

Titles containing non-Latin letters (Hebrew, Russian, Arabic…) are translated to English before the branch name is built.

Runs on your computer with the browser's own translation model, so titles never leave your machine. It needs Chrome 138 or newer, and the model is downloaded once per language.

Issue titles are sent to this service. Check that your company allows that. When you save, the browser asks for permission to contact it.

Format

Prohibited characters

When a prohibited character appears Quotes are always removed, so user's becomes users.

Limited characters

Characters that are allowed, but only a set number of times in the whole branch name, prefix included. Occurrences after the limit become the separator. For example, / limited to 1 keeps the slash in bugfix/ and turns login/logout into login-logout.
